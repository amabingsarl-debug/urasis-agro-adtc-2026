# Corpus provenance

The corpus contains short, original summaries written for this prototype. It does not reproduce source articles. Each JSONL record includes the organisation, public reference URL and language.

Primary reference families:

- FAO Integrated Pest Management and Fall Armyworm guidance
- FAO soil and water management resources
- FAO/WHO International Code of Conduct on Pesticide Management
- FAO food-loss, post-harvest and agricultural market information resources
- CABI Plantwise field-diagnostic principles

Before production deployment, the content must be reviewed with agronomists and extension services in each target country. Country-specific pesticide registrations, weather, outbreak alerts and market prices must never be treated as static offline facts.
