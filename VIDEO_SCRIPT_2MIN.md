# Two-minute demo script

## 0:00–0:15 — The problem

Visual: farmer, weak-connectivity symbol, ordinary laptop.

Voice-over: “Millions of African farmers work where Internet access is intermittent, API fees are unaffordable, and digital advice is rarely available in the language used in the field.”

## 0:15–0:30 — The solution

Visual: Urasis logo, then Aminata or Bakary as the agricultural avatar.

Voice-over: “Urasis Agro is a Swahili-first agricultural assistant that runs directly on an ordinary 8 GB laptop. Once installed, it needs no cloud, no Gemini request and no API credit.”

## 0:30–0:55 — Live Kiswahili question

Type: “Majani ya mahindi yangu yana mashimo na kinyesi ndani ya moyo. Nifanye nini?”

Show the model answering in Kiswahili with the four sections: situation, actions, monitoring and local help.

Voice-over: “It does not jump to a diagnosis. It asks for field observations, prioritizes integrated pest management and explains when an extension officer should inspect the crop.”

## 0:55–1:20 — Technical proof

Visual: disconnect network, run `llama-cli`, show Task Manager or `htop`, show profiler output.

Voice-over: “The model is Qwen2.5 3B, quantized to GGUF Q4_K_M and executed exclusively through llama.cpp. The weight file is about 2.1 gigabytes. A local agricultural retriever adds relevant guidance without uploading farmer data.”

## 1:20–1:42 — Accessibility

Visual: avatar speaking and pointing to an illustrated crop explanation.

Voice-over: “Urasis adds a human-facing avatar, speech and visual explanations. This is especially important for users who are more comfortable speaking than typing.”

## 1:42–2:00 — Vision

Visual: map with language names appearing: Kiswahili, Dioula/Jula, Baoulé, Wolof, Hausa, Yoruba, Twi, Amharic, Zulu.

Voice-over: “Kiswahili is our first African-language competition track, not our last. Our vision is a network of locally validated agricultural assistants, each running privately and affordably on the hardware communities already own. Urasis means: your assistant.”
